## What you can build

<AccordionGroup>
  <Accordion title="Creative features in your SaaS" icon="layer-group">
    Add AI image and video generation to your product without managing a dozen model providers. Pick a model with `list_models`, send a prompt, get a hosted file back.
  </Accordion>

  <Accordion title="E-commerce and marketing automation" icon="cart-shopping">
    Turn a product photo into campaign visuals, a vertical video or an Encore effect, then publish it to TikTok, Instagram Reels or YouTube Shorts.
  </Accordion>

  <Accordion title="No-code workflows" icon="diagram-project">
    Call the REST API from n8n, Make or Zapier with an API key: one HTTP request per generation.
  </Accordion>

  <Accordion title="AI agents" icon="robot">
    The Havincy MCP server exposes the same operations as tools. Agents choose the model, check credits, wait for the result and return the file.
  </Accordion>
</AccordionGroup>

## One API, two ways in

|  | REST API | MCP server |
| --- | --- | --- |
| Endpoint | `https://havincy.com/api/v1` | `https://havincy.com/mcp` |
| For | Your backend, scripts, no-code tools | ChatGPT, Claude, Cursor, Claude Code, any MCP client |
| Authentication | API key (`hv_live_…`) | OAuth sign-in (or an API key) |
| Operations | Same 16 operations | Same 16 operations, as tools |
| Billing | Your workspace credits | Your workspace credits |

Every generation is charged to the connected Havincy workspace, at the same price as in the app. See [Credits and limits](/credits-and-limits).

The OpenAPI spec is available at [`https://havincy.com/api/v1/openapi.json`](https://havincy.com/api/v1/openapi.json).
