---
title: "Get a generation"
api: "GET /generations/{id}"
---

Returns the status and file URLs of an asset created by a generation, an Encore creation or an upload. Status is `queued`, `processing`, `completed` or `failed`.

Required permission: `read`. MCP tool: `get_generation` (accepts several `asset_ids`).

<ParamField path="id" type="integer" required>
  Asset id.
</ParamField>

<ParamField query="wait_seconds" type="integer" default="0">
  Wait up to N seconds (0 to 25) for completion.
</ParamField>

<ResponseExample>

  "status": "completed",
