---
title: "List projects"
api: "GET /projects"
---

Lists the workspace projects, newest first. Use `project_id` in [List assets](/api-reference/list-assets) to get a project's media.

Required permission: `read`. MCP tool: `list_projects`.

<ParamField query="limit" type="integer" default="20">
  Page size (1 to 50).
</ParamField>

<ParamField query="starting_after" type="integer">
  Cursor: the `next_cursor` of the previous page.
</ParamField>

<ResponseExample>
```json 200
{
  "object": "list",
  "data": [
    { "id": 88, "object": "project", "title": "Summer campaign", "status": "ready", "brand_kit_id": 3, "app_url": "https://havincy.com/projets/88/atelier" }
  ],
  "has_more": false
}
```
</ResponseExample>
