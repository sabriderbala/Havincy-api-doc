---
title: "List publications"
api: "GET /social/publications"
---

Lists social publications, newest first.

Required permission: `read`. MCP tool: `list_publications`.

<ParamField query="status" type="string">
  `draft`, `ready`, `scheduled`, `publishing`, `published`, `partially_published`, `failed` or `cancelled`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Page size (1 to 50).
</ParamField>

<ParamField query="starting_after" type="integer">
  Cursor: the `next_cursor` of the previous page.
</ParamField>

<ResponseExample>
```json 200
{
  "object": "list",
  "data": [ { "id": 901, "object": "publication", "status": "published", "asset_ids": [5678], "deliveries": [] } ],
  "has_more": false
}
```
</ResponseExample>
